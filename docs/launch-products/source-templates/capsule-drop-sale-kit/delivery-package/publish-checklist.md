# Capsule Drop Sale Kit Publish Checklist

## Design Quality

- [ ] Replace all abstract product placeholders with licensed or original product imagery.
- [ ] Confirm every important text layer is editable in Figma.
- [ ] Confirm every important text layer is editable in Canva.
- [ ] Replace the Canva V2 banner offer fallback with a real detail-pass item.
- [ ] Check mobile readability on post and story exports.
- [ ] Export watermarked preview images.

## Product Page

- [ ] Product promise explains the business moment.
- [ ] Page shows the five-stage campaign journey.
- [ ] Page explains Figma and Canva delivery.
- [ ] Page states the non-exclusive license clearly.
- [ ] Page does not imply one-of-one ownership.
- [ ] AI Finder metadata matches fashion, ecommerce, boutique, capsule drop, sale, urgency, and quiet luxury.

## Delivery

- [ ] Figma link included.
- [ ] Canva folder link included.
- [ ] Exported PNG/WebP files included.
- [ ] README included.
- [ ] Commercial license included.
- [ ] Font and image license notes included.
- [ ] Final ZIP opens locally.
- [ ] Final ZIP is uploaded to storage.
- [ ] Product has a ready `delivery_zip` or `source_file` asset in admin.

## Publish Gate

Do not publish as a paid product until every blocker above is either checked or intentionally waived by the owner.
