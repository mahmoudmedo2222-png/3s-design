# Capsule Drop Sale Kit Font And Asset License Notes

## Fonts

- Final customer delivery must use fonts with clear commercial rights.
- If a font is from Canva, keep it available inside the Canva customer file.
- If a font is from Google Fonts or another provider, include the font name and license link before publishing.
- Do not ship paid font files unless the license explicitly allows redistribution.

## Images

- Current product surfaces use abstract placeholders.
- Public product previews need licensed or original fashion product imagery before launch.
- The buyer should be able to replace product images without breaking the layout.
- Do not include stock images in the final ZIP unless redistribution is allowed.

## Figma And Canva

- Figma is the source of truth.
- Canva files must be manually reviewed after Magic Layers conversion.
- The current Canva V2 banner offer item is a fallback copy and must be replaced or manually rebuilt before final sale.

## Launch Blockers

- Replace abstract product placeholders.
- Finish the Canva V2 banner offer as a real detail-pass item.
- Export watermarked public previews.
- Confirm font names and image rights.
- Build the final ZIP only after the above checks pass.
