# Starter Five Production Briefs

Use these briefs to build the approved Hybrid assets. Each product starts in Figma, then gets a Canva editable version, then exports and delivery ZIP.

## Shared Visual Rules

- No generic stock-template feeling.
- No oversized decorative cards inside cards.
- Use real product/use-case surfaces.
- Keep text editable in Figma and Canva.
- Keep typography polished and readable at mobile size.
- Use whitespace and hierarchy to create luxury.
- Every public preview gets a subtle `3S Design Preview` watermark.

## 1. Noir Dining Launch Kit

Slug: `noir-dining-launch-kit`  
Category: Restaurants and cafes  
Primary buyer: Premium restaurant owner  
Core emotion: expensive before booking

AI mood reference: `docs/launch-products/moodboards/noir-dining-launch-kit-mood-v1.png`

### Figma Frames

| Frame                    | Size      | Purpose                      |
| ------------------------ | --------- | ---------------------------- |

| `NDLK / Story / Booking` | 1080x1920 | Reservation story            |
| `NDLK / Menu / Cover`    | 1414x2000 | Menu cover direction         |
| `NDLK / Preview / Hero`  | 1600x1200 | Website product hero preview |
| `NDLK / Preview / Card`  | 1200x900  | Product card preview         |

### Copy

Headline options:

- Opening Night
- A New Table In The City
- Reserve The First Taste

Support copy:

- An intimate dining launch crafted for guests who notice detail.
- Black, gold, and warm editorial visuals for a premium restaurant reveal.

CTA options:

- Reserve Now
- View Menu
- Opening Soon

### Figma Direction

- Dark editorial composition.
- Use one hero food/dining image.
- Add small gold rule lines, but avoid heavy decoration.
- Keep a clear reservation or menu moment.

### AI Mood Prompt

```txt
Create a cinematic mood board for a luxury restaurant launch kit called Noir Dining Launch Kit. Use an elegant fine dining atmosphere with dark editorial surfaces, black marble, warm candlelight, subtle gold accents, premium menu paper, close-up plated dish details, and a refined reservation moment. The output should feel like a high-end editorial photography mood board, not a finished template. Use deep black, soft gold, warm ivory, muted charcoal, and subtle amber highlights. Avoid cheap restaurant flyer style, busy discount graphics, stock-looking smiles, neon signage, cluttered typography, excessive decoration, fake brand names, logos, and readable text.
```

### Canva Handoff

Editable fields:

- Restaurant name.
- Opening date.
- Reservation CTA.
- Menu section title.
- Contact/Instagram handle.

## Export Checklist

For each product:

- Export `product-card-preview.webp`.
- Export `website-hero-preview.webp`.
- Export `watermarked-preview.webp`.
- Export each usable frame as `.png`.
- Create `figma-link.txt`.
- Create `canva-link.txt`.
- Create `font-license-notes.md`.
- Create `commercial-license.txt`.
- Create `{slug}-v1.zip`.

## Internal QA

Before upload:

- Preview looks like the actual product.
- Text is readable on mobile.
- Canva copy is editable.
- Figma source is organized.
- ZIP opens correctly.
- License text is present.
- No private files are included.
