# Launch Catalog Blueprint

Use this when there are no finished designs yet. It defines what to create first so 3S launches with a focused premium catalog instead of random templates.

## Strategy

Start with 20 products across five buying moments:

- Food brands that need trust, appetite, and launch energy.
- Beauty/wellness brands that need calm luxury and visual softness.
- Real estate brands that need confidence and high-ticket polish.
- Ecommerce brands that need urgency without looking cheap.
- Events and invitations that need ceremony and memory.

The customer should feel that every product was designed for a business moment, not for filling a marketplace grid.

## What To Build In Figma

For each product:

1. Create a master frame named with the product slug.
2. Build one hero preview frame for the website.
3. Build 2-4 actual export frames.
4. Use consistent typography and spacing.
5. Add a small 3S watermark preview variant.
6. Keep source layers organized enough for paid customers.

Suggested Figma page structure:

```txt
01 Foundations
02 Product Masters
03 Preview Frames
04 Export Frames
05 Delivery Notes
```

## What To Build In Canva

For each product:

1. Create customer-editable versions for social formats.
2. Keep text editable.
3. Keep colors easy to change.
4. Duplicate the template for customer delivery.
5. Save the editable link in `source-notes/canva-link.txt`.

Canva is the customer convenience layer. Figma is the premium source layer.

## Creation Order

Start with these five because they cover the strongest launch story:

1. Noir Dining Launch Kit.
2. Glow Clinic Launch Kit.
3. Signature Property Carousel.
4. Luxury Sale Without Noise.
5. Elegant Wedding Invitation Suite.

After those five, the site can show real category breadth without looking empty.

## Quality Bar

Reject a design if:

- It looks like a generic marketplace template.
- It relies on a vague mockup instead of the actual design.
- It has no clear buyer moment.
- It cannot be reused commercially by multiple customers.
- It has no editable path through Figma or Canva.
- It does not improve AI matching because DNA is too vague.

The launch catalog should feel small, deliberate, and expensive.
